Project Overview

About the Project

Student Record Manager is a simple menu-driven Python program used to manage student records. It allows users to Add, Display, Update, Delete student records and display stored subjects using Python collections.

Objective

Add Student Records

Display All Students

Update Student Information

Delete Student Record

Display Stored Subjects

Exit Program

Data Structure Used

Each student record is stored as a Dictionary inside a List.

students = [
    {
        "id": "101",
        "name": "Alice",

Conclusion
Project Conclusion

This project demonstrates Python Lists, Dictionaries, Loops, Conditions, and the del keyword through a simple CRUD-based Student Record Management System. It is beginner-friendly, easy to understand, and suitable for Red & White Skill Education project submission.
